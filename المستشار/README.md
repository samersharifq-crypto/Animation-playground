# المستشار — تطبيق مرشد نفسي بالذكاء الاصطناعي

مرشد نفسي عربي بلهجة خليجية، يساعد المستخدم بشكل خفيف في التعامل مع مشاكله اليومية.
**ليس بديلاً عن الطبيب أو المعالج النفسي.**

---

## الفكرة باختصار

- تطبيق محادثة متصل بنموذج لغوي (Claude عبر الـ API).
- لا نحتاج تدريب نموذج من الصفر، بل:
  - **تعليمات نظام** تحدد شخصية المستشار وأسلوبه وحدوده.
  - **قاعدة معرفة (RAG)** عند الحاجة لمحتوى خاص.
  - **ذاكرة جلسات** ليتذكر سياق المستخدم.

## الأساس العلمي

**الأساس الرئيسي:** مناهج حديثة مثبتة علمياً:
- العلاج المعرفي السلوكي (CBT): للقلق والتفكير السلبي.
- العلاج بالقبول والالتزام (ACT).
- المقابلة التحفيزية: للعادات وتغيير السلوك.
- مهارات DBT: لتنظيم المشاعر.

**طبقة إضافية:** أفكار يونغ وفرويد (الأحلام، النماذج الأصلية، الظل) للتأمل الذاتي وتفسير الأحلام كميزة مميزة.

**ملاحظات:**
- لا داعي لتصوير الكتب؛ النموذج يعرف هذه النظريات.
- حقوق النشر: الترجمات وكتب يونغ والكتب الحديثة غالباً محمية، فلا نضع نصوصها داخل التطبيق.

## الميزة التنافسية

- يفهم اللهجة الخليجية.
- يراعي الثقافة والقيم والعائلة والمجتمع.
- يحفظ الخصوصية (كثير من الناس يستحون يروحون لمعالج).

## شروط الأمان (إلزامية)

- [ ] **كشف الأزمات:** عند ذكر إيذاء النفس أو الانتحار، يتوقف الإرشاد ويُعطى المستخدم أرقام الطوارئ وخطوط الدعم فوراً.
- [ ] **توضيح صريح** أنه دعم خفيف وليس علاجاً.
- [ ] **حماية البيانات** وتشفير المحادثات.
- [ ] **الأنظمة المحلية** للتطبيقات ذات الطابع الصحي.
- [ ] **مراجعة أخصائي نفسي** قبل الإطلاق.
