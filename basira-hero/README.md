# «سمّوه البطل» — شورت بصيرة (أمة الدوبامين ٤)

شورت عمودي 1080×1920، مدته 65 ثانية، ويتحرك بأسلوب الستوب موشن (12 إطارًا في الثانية). فيه ورق ممزّق، وكلمات تظهر كلمة كلمة مع الصوت، ومؤثرات صوتية بلا موسيقى.

النسخة الحالية `basira_hero_v1_preview.mp4` معاينة لضبط التوقيت. فيها صور مؤقتة مرسومة في مكان صور Gemini، والتوقيت فيها تقديري لأن الصوت لم يُسجَّل بعد.

## ما رُسم بالكود (جاهز ونهائي)
القارورة وملصقها، وحروف HEROIN التي تُطبع حرفًا حرفًا ثم يحمرّ منها HERO، والوسام الذي يتأرجح ثم يسقط، وشرخ الزجاج، والميزان الورقي، والعدّاد (×2 ← ×5 و4 ← 20,000)، والساعة، والسجائر التي تنهمر، والإشعارات، وأشرطة أقوى · أسرع · أكثر.

## المطلوب منك
ضع الملفات في `assets/` بهذه الأسماء:

| الملف | ما هو |
|---|---|
| `chemist_k1.png` | الكيميائي، الوضعية ك١ |
| `chemist_k2.png` | الكيميائي، الوضعية ك٢ |
| `worker.png` | العامل |
| `young.png` | الشاب |
| `lab.png` | المختبر (9:16) |
| `factory.png` | المصنع (9:16) |
| `machine.png` | الآلة (على خلفية بيضاء) |
| `room.png` | الغرفة الكحلية، من ملف المشروع |
| `logo.png` و`logo_eye.png` | الشعار الكامل، ثم إطار «الباء بالعين»، بخلفية شفافة |

صورة مرجع الكيميائي تحتاجها فقط لتوليد الوضعيتين، ولا تدخل في الفيديو.

وضع الصوت في `narration/P1.wav` و`narration/P2.wav`. أي صيغة يقرؤها ffmpeg تصلح (m4a وmp3 وغيرهما).

## التشغيل
```bash
pip install numpy scipy pillow     # ومعها ffmpeg، وPillow مع دعم raqm للعربية
python3 prepare.py                 # يقصّ الصور، ويضع صورًا مؤقتة مكان الناقص
python3 hero.py sheet 1.5 11 18.8 26.8 41 48.9 54.5 60.5   # إطارات للفحص -> sheet.png
python3 hero.py 0 390 & python3 hero.py 390 780 & wait      # كل الإطارات
python3 tools/sound.py             # المؤثرات + الصوت -> mix.wav
python3 hero.py encode basira_hero_v2.mp4
```

كل التوقيتات موجودة في `cues.py`. بعد التسجيل نقيس توقيت كل كلمة ونعدّل هذا الملف وحده، فتتحرك معه المشاهد والكلمات والمؤثرات.
