# بصيرة — brand files

The official Basira logo. Use these files for every video, short and thumbnail; do not redraw the logo.

| File | Use |
|---|---|
| `basira-logo-banner.png` | Original banner (5120×2880, cream background) |
| `basira-mark-square.png` | Original square mark (1600×1600, cream background) |
| `basira-logo-transparent.png` | Full logo (wordmark, tagline, mark), transparent, for light backgrounds |
| `basira-logo-on-dark.png` | Full logo, transparent, ink turned cream, for dark backgrounds |
| `basira-mark-transparent.png` / `basira-mark-on-dark.png` | The ب mark with the eye, alone |
| `basira-wordmark-transparent.png` / `basira-wordmark-on-dark.png` | «بصيرة» + «نرى ما وراء الحكاية» + «تاريخ · علوم · وثائقيات · تأملات» |
| `piece-ba-stroke.png` / `piece-ba-stroke-on-dark.png` / `piece-eye.png` | The mark split into the ب stroke and the eye, for animating (eye rests centred under the stroke, its centre 198 px below the stroke's bottom edge at the square file's scale) |

## Colours

- Ink (navy): `#18222E` — rgb(24, 34, 46)
- Eye / accent (brick red): `#B4482A` — rgb(180, 72, 42)
- Paper (cream): `#F1EBDF` — rgb(241, 235, 223)

## Tagline

«نرى ما وراء الحكاية» — subtitle line «تاريخ · علوم · وثائقيات · تأملات».
